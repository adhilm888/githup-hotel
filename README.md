# Marriott Sydney — Hotel Website

A responsive luxury hotel website created as a student
web-development project.

## Project

This project is a modern hotel website concept called:

**Marriott Sydney**

It includes:

- Luxury hotel homepage
- Hero section
- Rooms & Suites
- Dining section
- Sydney experience section
- Events section
- Hotel amenities
- Booking interface
- Contact section
- Responsive mobile navigation
- Demo availability interaction

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Unsplash images
